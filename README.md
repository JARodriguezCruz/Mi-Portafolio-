# 🚀 Portfolio — Jonathan A. Rodriguez Cruz
### Jr. Full Stack Java Developer

Portafolio personal desarrollado con HTML5, CSS3 y JavaScript puro.  
Diseño dark mode moderno con animaciones, terminal interactiva y proyectos reales de GitHub.

---

## 📁 Estructura del proyecto

```
portfolio-jonathan/
│
├── index.html          ← Página principal
├── css/
│   └── styles.css      ← Todos los estilos (variables, layout, componentes)
├── js/
│   └── main.js         ← Lógica: cursor, terminal, filtros, animaciones
├── assets/             ← Carpeta para imágenes o íconos futuros
│
└── .vscode/
    ├── settings.json       ← Configuración del editor
    └── extensions.json     ← Extensiones recomendadas
```

---

## 🛠️ Tecnologías utilizadas

- **HTML5** — Estructura semántica
- **CSS3** — Variables CSS, Flexbox, Grid, animaciones
- **JavaScript (ES6+)** — Cursor, terminal, filtros, scroll reveal
- **Google Fonts** — Plus Jakarta Sans + Space Mono
